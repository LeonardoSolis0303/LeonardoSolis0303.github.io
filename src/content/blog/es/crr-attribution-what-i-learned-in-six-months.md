Dejé el trabajo para terminar la tesis, pero antes de irme quería documentar el proyecto quant que empecé. Un CRR attribution layer no es glamoroso, pero te enseña a pensar en riesgo de una manera muy concreta.

Lo más importante que aprendí: la diferencia entre un modelo que funciona y uno que es correcto. Nuestro modelo funcionaba. No estoy seguro de que fuera correcto.

Stack: PostgreSQL para los datos históricos, SQLAlchemy como ORM, Pandas para el análisis, Azure Data Studio para visualizar.
